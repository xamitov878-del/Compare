# Product Comparison Widget

Небольшое приложение для сравнения товаров на React и JavaScript.

### Что сделано

* Можно выбрать до 3 товаров для сравнения
* Можно удалить товар из сравнения
* Сравнение отображается в виде таблицы
* Выбранные товары сохраняются после перезагрузки страницы

### Почему так

* Использовал `useState` для хранения выбранных товаров
* Использовал `localStorage`, чтобы сохранять данные после обновления страницы
* Разделил приложение на компоненты для удобства работы с кодом

vercel   https://compare-a.vercel.app

### Запуск


npm run dev
