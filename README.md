# Product Comparison Widget

Небольшое приложение для сравнения товаров, созданное на React и JavaScript.

## Что сделано

* Можно выбрать до 3 товаров для сравнения
* Можно удалить товар из сравнения
* Сравнение отображается в виде таблицы
* Выбранные товары сохраняются после перезагрузки страницы
* Для разных категорий (Cars, Phones, Pieces и др.) сделаны отдельные страницы

## Использованные технологии

* **React** — для создания интерфейса.
* **React Router** — для перехода между страницами приложения.
* **JavaScript** — для логики приложения.
* **SCSS** — для удобного написания и организации стилей.
* **localStorage** — для сохранения выбранных товаров после обновления страницы.

## Почему так

* Использовал `useState` для хранения выбранных товаров.
* Использовал `React Router`, чтобы разделить приложение на отдельные страницы.
* Использовал `SCSS`, чтобы стили было проще писать и поддерживать.
* Использовал `localStorage`, чтобы после обновления страницы выбранные товары не исчезали.
* Разделил приложение на компоненты, чтобы код был более понятным и удобным.
